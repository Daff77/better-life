# Perbaikan prioritas 4–6

- Jurnal mempertahankan porsi pecahan, menskalakan makro saat porsi berubah, dan menunjukkan selisih kalori negatif. ID client diterima server sebagai upsert per pengguna sehingga retry tidak menggandakan entri. Edit, tambah, hapus, dan reset disimpan dalam antrean lokal per akun; retry terjadi saat hidrasi atau operasi jurnal berikutnya. Reset wajib menyebut tanggal.
- Onboarding memakai fungsi kalkulasi domain yang sama dengan tes. Planner tidak kembali ke resep yang melanggar filter ketika kandidat aman habis. Padanan Lactose, Nuts, Seafood ditambahkan dan penggantian resep lokal diperiksa.
- Checkout/receipt provider nyata ditolak karena integrasi verifikasi belum tersedia. Sandbox harus diaktifkan eksplisit melalui ENABLE_PAYMENT_SANDBOX=true dan tetap dilarang dalam production. Endpoint webhook dinonaktifkan sampai verifikasi provider tersedia. Mobile tidak lagi membuat premium lokal setelah kegagalan checkout, verify, cancel, atau restore.

Pembayaran nyata belum diimplementasikan: konfigurasi provider dan integrasi verifikasinya diperlukan. Antrean jurnal mencoba kembali saat aplikasi membuka atau mengubah jurnal; belum ada scheduler background. Backend masih memakai penyimpanan memori sesuai temuan audit terpisah.

Verifikasi: tes backend dan mobile, TypeScript, serta build backend/Expo web. Tes perangkat fisik dan pembayaran provider nyata belum dijalankan. Perubahan belum di-push.
